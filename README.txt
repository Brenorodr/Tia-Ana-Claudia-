ARQUIVOS SEPARADOS — BLOG TIA ANA CLÁUDIA

Gerado a partir do arquivo enviado pelo usuário.

Arquivos:
- index.html  -> estrutura HTML
- style.css   -> 4 blocos de CSS inline, preservados na ordem original
- script.js   -> 8 blocos de JavaScript inline
- ORIGINAL_Markdown.md -> cópia do arquivo original enviado

Observação:
- O HTML original é um template/renderização do Blogger. Alguns trechos dependem
  de serviços e scripts do próprio Blogger e de serviços externos.
- Scripts externos foram mantidos no index.html porque são dependências externas,
  não código local do site.
- Esta separação é uma etapa de organização; ainda não significa que o site esteja
  pronto para funcionar como site estático independente do Blogger.
- O CSS e JS foram preservados sem "modernizar" ou corrigir o código, para manter
  uma cópia fiel antes da reformulação.
